# V2 模板库与 Header 改版设计方案

## 1. Header 改版

### 样式参考
参考 `../GenTool/infinite-canvas/web/src/components/layout/app-top-nav.tsx`

### 结构
```
┌─────────────────────────────────────────────────────────────────┐
│  [Logo] AI制图    生图工作台 | 模版库 | 我的素材        [消息] [用户]  │
└─────────────────────────────────────────────────────────────────┘
```

### 规格
- `sticky top-0 z-20 h-16`
- `border-b border-stone-200`
- `bg-background/90 backdrop-blur-xl`
- 最大宽度容器 `max-w-7xl mx-auto px-6`
- Logo 区：logo SVG + "AI制图" 文字
- 导航区：3 个 Tab，带 Lucide icon，active 状态有底部下划线
- 右侧区：消息通知铃铛 + 用户头像下拉菜单

### 导航 Tab
| Tab | 路由 | 说明 |
|-----|------|------|
| 生图工作台 | `/ai-image/v2` | 当前主工作台页面 |
| 模版库 | `/ai-image/v2/templates` | 新页面，提示词库 |
| 我的素材 | `/ai-image/v2/assets` | 图片库迁移至此 |

### 交互
- Logo 点击 → 返回首页 `/`
- Tab active 状态：底部下划线高亮
- 消息铃铛：显示未读红点
- 用户头像：下拉菜单（设置、登出）

## 2. 完全空白模板

### 定义
- 无任何系统规则注入
- prompt 直发 LLM
- 纯实验性、完全自由的创作模式

### 实现
- 在 `SYSTEM_TEMPLATE_PROFILES` 中增加 `tpl-blank-free`
- `templatePrompt` 为空字符串
- `configV2` 标记 `mode: "free"`
- 构建器检测到 `free` 模式时跳过所有模板规则注入

### 在模板库中的呈现
- 作为普通模板卡片出现在网格中
- 标签：空白 / 自由创作
- 示意图：极简风格占位图

## 3. 模板库页面（独立页面）

### 路由
`/ai-image/v2/templates`

### 布局
```
┌────────────────────────────────────────────────────────────┐
│  筛选区（标签过滤）                                           │
│  [全部] [电商] [角色] [故事板] [我的] [收藏]                  │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐      │
│  │ [示意图]  │ │ [示意图]  │ │ [示意图]  │ │ [示意图]  │      │
│  │          │ │          │ │          │ │          │      │
│  │ 模板标题  │ │ 模板标题  │ │ 模板标题  │ │ 模板标题  │      │
│  │ #标签     │ │ #标签     │ │ #标签     │ │ #标签     │      │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘      │
│                                                            │
│  ...                                                       │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 筛选标签（Tab 形式）
| 标签 | 说明 |
|------|------|
| 全部 | 显示所有模板 |
| 电商 | 当前所有 12 个系统模板（hero、promo、feature 等） |
| 角色 | 留空（后续补充） |
| 故事板 | 留空（后续补充） |
| 我的 | 用户保存的自定义模板 |
| 收藏 | 占位（后续做收藏功能） |

### 模板卡片规格
- 宽度：自适应网格（4-5 列，响应式）
- 内容：示意图（颜色块 + 风格图标）+ 标题 + 标签行
- 示意图：静态，每个模板一种主色调 + Lucide 图标
- 标签：显示所属分类标签

### 模板详情弹窗
- 点击卡片 → 打开详情 Dialog
- 内容：大图示意图 + 模板名称 + 详细描述 + 标签列表
- 底部按钮：「使用此模版」
- 点击「使用此模版」→ 关闭弹窗，跳转到生图工作台并加载该模板

### 空白模板的呈现
- 出现在「全部」和「电商」标签下
- 卡片标题：空白模板 / 自由创作
- 示意图：纯白背景 + 画笔图标
- 标签：#自由 #实验
